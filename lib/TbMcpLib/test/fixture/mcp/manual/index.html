TrenchBroom Test Reference Manual

Introduction

TrenchBroom is a level editing program for brush-based game engines such as Quake, Quake 2, and Hexen 2. It's easy to use & fast.

Features

  • General
    • Full support for editing in 3D and in up to three 2D views
    • Unlimited Undo and Redo
  • Brush Editing
    • Robust vertex editing

Vertex Editing

The vertex tool edits the vertices of brushes. Select brushes and choose to activate the vertex tool.

Vertices can be moved, merged and split. Moving a vertex onto another vertex merges the two vertices. Brushes stay convex while vertices are moved; the tool removes vertices that would make a brush concave.
